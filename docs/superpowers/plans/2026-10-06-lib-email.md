# Biblioteca interna de e-mail do backend — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Centralizar todo o envio de e-mail do backend no pacote `app.email`, com provedores Brevo/SMTP/console, e migrar os chamadores para ele.

**Architecture:** Pacote Python `backend/app/email/` com funções puras de mensagem, provedores plugáveis por função e um núcleo de seleção por configuração. Os chamadores usam apenas `send_reset_email` e `send_first_access_email`. O módulo antigo `app/services/email_service.py` é removido.

**Tech Stack:** Python 3, FastAPI, pydantic-settings, smtplib e urllib (biblioteca padrão). Sem novas dependências de terceiros.

**Spec:** `docs/superpowers/specs/2026-10-06-lib-email-design.md`

## Global Constraints

- Base branch: `feature/esqueci-minha-senha-envio-email`.
- Não adicionar dependências novas; usar apenas `smtplib` e `urllib.request` da biblioteca padrão.
- Toda configuração vem de `app.core.config.get_settings()`; provedores não leem variáveis de ambiente diretamente.
- Ordem de seleção de provedor: Brevo → SMTP → console.
- Textos de mensagem em português, idênticos aos já existentes; assunto de reset = `SGA ABACO - Recuperação de Senha`; assunto de primeiro acesso = `SGA ABACO - Conta criada com sucesso`.
- Links: `{frontend_url}/reset-password?token={token}` e `{frontend_url}/first-access?token={token}`.
- O provedor de console nunca registra o token completo; sempre mascarado.
- `EmailDeliveryError` é o único erro de entrega; a biblioteca nunca o engole.
- Rodar testes a partir de `backend/`: `python -m pytest`.

## Review Focus

- **Chave Brevo em branco.** `BREVO_API_KEY=""` ou só espaços não deve ativar o Brevo; deve cair para SMTP/console. Um `if settings.brevo_api_key` com string `"   "` é truthy e quebraria o fallback. Task 5 cobre com teste.
- **Erro HTTP do Brevo.** `urllib` levanta `HTTPError` para respostas >= 400. Precisa virar `EmailDeliveryError` e o corpo do erro não pode vazar credencial. Task 4 cobre.
- **Porta SMTP 465.** Deve usar `SMTP_SSL`, não `SMTP.starttls()`. Task 3 cobre os dois caminhos.
- **Mascaramento sem token.** Corpo sem `token=` não pode quebrar o regex de mascaramento nem registrar o corpo cru. Task 2 cobre.
- **Import obsoleto.** Após remover `app/services/email_service.py`, qualquer import restante deve falhar. Task 7 roda a suíte completa do backend.
